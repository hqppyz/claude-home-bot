# Contributing

## Commit messages

Follow [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/):

```
<type>[optional scope]: <description>

[optional body]

[optional footer(s)]
```

- `type` is one of `feat`, `fix`, `docs`, `refactor`, `test`, `chore`, `build`, `ci`, `perf`, `style`, `revert`.
- `description` is lowercase, imperative ("add", not "added"), with no trailing period.
- Mark breaking changes with `!` after the type (`feat!: ...`) or a `BREAKING CHANGE:` footer.
